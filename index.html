NEXUSPLAY MUSIC

📝 Comment ajouter tes musiques

1. Va sur YouTube, trouve la musique que tu veux

2. Clique sur Partager → Intégrer et copie le code <iframe>

3. Ou copie juste l'ID vidéo (dans l'URL après v=)

4. Ajoute une ligne dans le tableau TRACKS en bas du code

Exemple : { name: "M.R.H", artist: "Boro 700", id: "dQw4w9WgXcQ" }
